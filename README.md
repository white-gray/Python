# Сбор данных и внесение изменений сразу по нескольким системам
написанное на Python

> *Более подробное описание действия и возможностей скриптов находятся в текстах самих скриптов*


## forBlockingUsers_Pythin2.7.py
* Скрипт написан для обработки заявок Jira по удалению данных в системах телефонии (Naumen + Avaya IPO SE) по уволившимся пользователям.
* Также даются комментарии по удалению данных по этим пользователям в FMTN.
 
  > *(даннуе собираются по Jira, Active Directory, Naumen, Avaya IPO; и изменения вносятся в системы Naumen и IPO)*
	
	> При исполнении скрипта ведется log файл, в котором выводятся действия о процессе, и конечные данные.
